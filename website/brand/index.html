( Idea )

One shape, four meanings.

( Logo )

The word is made of the same dots.

The letters are drawn one dot at a time on a 5 × 7 grid, at the same pitch as the ring. No font is involved, so the logo looks the same everywhere.

  • ( A )Ink or white only, plus the one red dot. No gradients, no glow, no second colour.
  • ( B )Clear space all round: three gaps between ring dots. The files include it.
  • ( C )Below 48px, use the small mark: the same C from fewer, bigger dots.
  • ( D )Never redraw the dots as other shapes, and never put the mark in a coloured container.
